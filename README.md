# BookBot

BookBot is a Python command-line program that analyzes the text of a book.

## Features

- Total word count
- Character frequency
- Character frequency sorted by occurrence

## Usage

Analyze a book by providing its path:

    python3 main.py books/frankenstein.txt

Other included books:

    python3 main.py books/mobydick.txt
    python3 main.py books/prideandprejudice.txt

## Requirements

- Python 3
